# Library E-Card Management System

A web-based Library E-Card Management System developed using Flask, SQLite, HTML, and CSS.

## Features

* Student Registration
* Student Login
* Admin Login
* Passport Upload
* E-Card Generation
* QR Code Generation
* QR Code Verification
* Student Dashboard
* Admin Dashboard
* Student Search

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS

## Project Workflow

1. Student registers for a library card.
2. Admin views student information.
3. Admin generates an E-Card.
4. Student logs in to view the E-Card.
5. Library staff verifies the E-Card using QR code scanning.
